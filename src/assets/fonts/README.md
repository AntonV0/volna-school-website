# Local Geist fonts

Variable fonts bundled for reliable builds without Google Fonts requests.
Both support weights 100–900 and include the upstream character sets.

Downloaded from the Google Fonts repository on 2026-09-09:

- https://github.com/google/fonts/tree/main/ofl/geist
- https://github.com/google/fonts/tree/main/ofl/geistmono

Each family is distributed under the SIL Open Font License; the corresponding
`*-OFL.txt` file is included alongside the font.
